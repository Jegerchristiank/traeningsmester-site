# Visuel revision — Træn videre

Kvalitetsreference: Apple (produktpræcision, typografisk hierarki og rytme), sammen med appens godkendte fotografiske paywall-reference. Træningsmesters retning, indhold og framework er fastholdt. Denne revision er kun til preview.

| Brugerbehov | Kvalitetskriterium | Evidens / terminaltilstand |
| --- | --- | --- |
| Forstå produktet straks | Sammenhængende appvisning og læsbart sæt; afbalanceret hero; produkt synligt tidligt på mobil | Nye desktop- og mobilcaptures, sammenlignet med udgangspunktet |
| Følge samme træning | Program → 62,5 kg × 8 → pause → samme registrering i historik | Faktisk scrolling og kapitelknapper; kildefaste eksempeldata |
| Kunne tilmelde sig trygt | Én formular, bevaret samtykke, feltfejl og serverbekræftet succes | Browserkontrol med interceptede svar, ingen rigtige mails |
| Forstå muligheder og afsender | Redaktionel rytme, korrekte statusoplysninger, ingen billedmæssig personforveksling | Hele siden gennemset ved desktop/mobil |
| Brugbart preview | Semantisk HTML, tastatur, reduceret bevægelse, ingen ventetid på intro | Playwright, browser, build og sammenlignelig performancekontrol |
| Sammenhængende omtale | Still, klip og dansk opslag følger endelig komposition | Eksporterede assets gennemset; intet publiceres |

Status ved start: første leverances visuelle kvalitet er underkendt af brugeren. Teknisk funktion alene opfylder ikke denne revision.
